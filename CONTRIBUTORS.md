# Contributors

Everyone who has contributed to `python-docx-ng`, newest release first.

Thank you — every one of these arrived unsolicited.

## 2.0.0

- [@lyydsheep](https://github.com/lyydsheep) — `os.PathLike` support throughout document
  open and save, including the extracted-directory branch that previously went unnoticed
  ([#130](https://github.com/toxicphreAK/python-docx-ng/pull/130))
- [@builtbyhuy](https://github.com/builtbyhuy) — XPath variable binding, so style names
  containing quotes are reachable instead of raising from three layers down
  ([#131](https://github.com/toxicphreAK/python-docx-ng/pull/131))
- [@BortnikMaxim](https://github.com/BortnikMaxim) — table alternative text, `Table.title`
  and `Table.description`
  ([#132](https://github.com/toxicphreAK/python-docx-ng/pull/132))

`python-docx-ng` builds on [python-docx](https://github.com/python-openxml/python-docx)
by [Steve Canny](https://github.com/scanny) and its contributors. The
[contributors graph](https://github.com/toxicphreAK/python-docx-ng/graphs/contributors)
covers the commit history this repository inherited.

Patches are welcome — see [CONTRIBUTING.md](CONTRIBUTING.md).
